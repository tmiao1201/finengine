# finengine 设计文档 —— 大模型集团财务模型 Excel Package

日期：2026-08-25 ｜ 状态：已批准（用户逐节确认）

## 1. 定位

求职作品集旗舰：从零手搓的集团财务分析 Excel package，虚构"智擎集团"（参考智谱商业模式：MaaS/私有化/C端），Python+openpyxl 全公式生成，可复现、可版本管理、改假设全模型联动。

## 2. 核心需求（用户确认）

- 真合并报表：母公司+3子公司+关联交易+内部抵消+关联方对账
- 前后勾稽：三表全勾稽，8 组断言全绿才交付
- 四下拉维度：主体/业务线/地区/期间（含"全部"）
- 期间：2023A-2027E 年度
- UE 模型 + 项目评估（NPV/IRR+敏感性）
- 单体厚度 1b：研究院全量三表，子公司 IS 全量+BS/CF 关键科目

## 3. 集团架构

| 主体 | 角色 | 对外收入 | 持股 |
|---|---|---|---|
| 研究院（HoldCo） | 基座模型研发、训练算力 | 无（关联收入） | — |
| 智擎云 | MaaS API（token 计费） | MaaS | 100% |
| 智擎行业 | 私有化+解决方案 | 两条业务线 | 100% |
| 智擎互联 | C端 App | 订阅+广告 | 80%→少数股东 |

业务线 5：MaaS/私有化/解决方案/C端订阅/广告及其他。地区 4：华东/华北/华南/海外。
维度适用性：IS 全四维；BS/CF 仅主体×期间（科目无业务线属性）。

## 4. 关联交易与抵消

- T1 license 年费：研究院→三家，=子公司收入×费率（云12%/行业8%/互联10%）。定价叙事=成本加成参考，受支付能力约束（转让定价话题）
- T2 定制研发服务：研究院→行业，项目额假设
- T3 推理算力转售：云→互联，内部价=对外×80%
- T4 内部往来：60 天账期，期末挂应收/应付
- E1 关联收入/成本对冲；E2 内部往来对冲；E3 少数股东损益拆分；合并 CF 间接法（内部结算自动消失）
- 简化假设（明示）：内部服务当期结转、无未实现利润抵消；所得税不结转亏损
- IC_Recon：4×4 双边对账矩阵 + 一笔故意埋的 cut-off 在途（互联12月确认/云1月开票，¥220万）→ 调节表归零

## 5. 勾稽架构（倒挤现金法）

1. IS 公式独立推导
2. BS 非现金科目由假设驱动（DSO/DPO/递延率/capex滚动/RE滚动）
3. **BS cash = 负债+权益−非现金资产（倒挤→BS 结构性平衡）**
4. CF 间接法独立推导期末现金
5. C2 断言：CF 现金 = BS 倒挤现金（全模型最深勾稽线）

## 6. 验证架构（双引擎交叉）

- **影子引擎**：engine.py 用 Python 纯算一遍全部数字（dict 树）
- **Excel 公式**复刻同样逻辑
- formulas 库重算 xlsx → 逐格对比 Python 值 → 断言全绿
- Dashboard"全部"=通配符 `*`（已冒烟验证）；备选 SUMPRODUCT

## 8. 分工 DAG 与检查点

M0 地基(串行)→Gate1 假设量级审→M1 单体×4(并行)→Gate2 各主体BS平→M2 关联层→M3 合并层→Gate3 合并勾稽→M4 Dashboard/UE/ProjectEval(并行)→M5 Checks+美化→Gate4 端到端重算全绿+用户打开确认。

subagent 契约：输入=engine.py 输出 schema+布局约定+样式模块；输出=该 sheet 生成器脚本+影子值对比证据。
