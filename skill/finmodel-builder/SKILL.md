# finmodel-builder — 手搓可勾稽验证的全公式财务模型 Excel Package

用 Python+openpyxl 生成**活的**财务模型：改一个蓝字假设，全模型重算，勾稽断言实时亮灯。
**核心信仰：完成 = 有证据——每一格数字都有影子引擎双算背书，绝不说"应该可以了"。**

## 触发场景

- "帮我做一个 XX 公司的财务模型 / 三表模型 / 预算包"
- "从零手搓一个集团财务分析 Excel package"
- "做一个改假设能联动、前后勾稽的模型"
- "把这套财务逻辑做成带下拉维度的看板"

## 前置条件（先冒烟，再动工）

```bash
python3 -m venv .venv && .venv/bin/pip install openpyxl formulas
# 冒烟：验证 formulas 重算链路 + 关键函数支持（SUMIFS 通配符 "*" / NPV / IRR / IFERROR）
# 写 20 行小 xlsx → formulas.ExcelModel().loads().finish().calculate() → 读回断言
```

冒烟不过不要开工——整条验证架构押在 formulas 上。LibreOffice headless 是备选重算器。

## 五支柱方法论

### 1. 影子引擎双算交叉验证（最重要的架构决策）
- `engine.py`：Python 纯算出全部数字（dict 树）+ 17 项勾稽断言，**先全绿**
- Excel 公式复刻同一逻辑，每格注册期望值
- `formulas` 重算 xlsx → 逐格对比影子值 → 全部一致才算过
- 效果：bug 无处藏身（本次实战影子层抓出 6 个口径 bug，Excel 层抓出 3 个）

### 2. 倒挤现金法（BS 结构性平衡，免循环引用）
- BS 非现金科目由假设驱动（DSO/DPO/递延率/capex 滚动/RE 滚动）
- **BS cash = 负债+权益−非现金资产**（倒挤 → 资产负债表永远平）
- CF 间接法独立推导期末现金
- 断言 `CF现金 = BS现金`——全模型最深的勾稽线
- 期初数必须同口径倒挤（期初现金 = 期初权益−期初非现金资产），否则第一年恒等式破

### 3. Layout 坐标注册器（subagent 分工的契约核心）
- `L.reg(sheet, key, row, expected)` 登记 坐标↔语义key↔影子期望值
- 生成器只通过 `L.ref()` 拼公式引用，坐标只有一处真相
- 多 agent 并行写 sheet 不冲突：各自 `gen(wb, L, eng)`，最后 build 拼装
- `recompute.py` 用注册表做逐格验证

### 4. 分层 DAG + Gate（graph engineering）
```
M0 地基(assumptions+engine+契约) → Gate1 影子断言全绿
→ M1 单体层(可并行) → Gate2 各主体 BS平/CF勾稽
→ M2 关联层 → M3 合并层 → Gate3 合并勾稽
→ M4 分析层(N subagent 并行) → M5 Checks+Cover → Gate4 端到端全绿
```
每张 sheet 底部自带 `★ 差异行`（应全 0）——证据长在表里，不靠嘴说。

### 5. 财务建模惯例（Excel 层）
- 蓝字=输入、黑字=公式、绿字=跨表链接；负数红色括号千分位
- 年份列头用数字 + number_format `'0"A"'/'0"E"'`（显示 2023A 但可参与公式）
- 合并三表 = Σ单体−抵消；间接法 CF 让内部结算自动消失
- Checks 面板：8 组断言 + `IF(AND(ABS(...)<0.01,...),"PASS","FAIL")` + 总灯

## 集团层设计要点（合并报表时）

- 母公司收入全为关联交易 → 单体看盈利、合并后消失，故事性最强
- 关联对冲注意：**合并 COGS 要保留服务提供方的真实成本**（如 0.55×内部交易额），只抵内部定价差——内部利润随对方对外收入实现
- 内部往来双边挂账要逐笔配平；故意埋一笔 cut-off 在途（对方已确认、己方未开票）→ 对账矩阵亮差异 → 调节表归零 → 合并挂"其他应付款-在途"
- 长投成本法 vs 合并按份额冲抵，差额进合并资本公积（明示简化，不追溯权益法）
- 非全资子公司：少数股东损益 = NI×少数比例；少数股东权益 = 净资产×比例

## 已知陷阱（全部实战验证）

| 坑 | 现象 | 解法 |
|---|---|---|
| `"<>"` 非空匹配 | formulas 引擎对**数字列**匹配不到 | 数字维度"全部"用 `">0"`，文本列用 `"*"` |
| 明细+合计双算 | 数据仓同时存合并行和单体行，`"*"` 双算 | 条件格 `IF(选="*","<>合并",选)` |
| 备注文本以 `=` 开头 | formulas 当公式编译报 FormulaError | 备注列禁止 `=` 开头 |
| 常量行只写一列 | 后续列空 → 公式乘出 0 | 常量写满全列同值 |
| 滚动行前向引用 | 公式引用"上一列同行"时行号未定 | 先取 `row=r` 再构造 `{chr(66+i)}{row}` |
| IRR 无解 | 现金流全正（无前期垫资）返回 #NUM! | `IFERROR(IRR(...),"—")` 注明以 NPV 排序 |
| 影子与 Excel 口径漂移 | 单边改了口径另一边没跟 | 每处口径分歧必须当场对齐并写进 recompute |

## Red Flags

- 影子引擎断言没全绿就开始写 Excel 层 → 停，先修引擎
- 生成器里出现手写数字而非公式/引用 → 破坏"改假设联动"承诺
- 没跑 `recompute.py` 就宣布完成 → 违反"完成=有证据"
- Checks 面板有 FAIL 但交付了 → 红灯就是不可交付
